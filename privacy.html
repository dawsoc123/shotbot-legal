Privacy Policy

Last updated: November 18, 2026

This policy explains what data shotbot uses, why, where it is kept and how to delete it. shotbot is a personal desktop application that runs only on its owner's own computer. It has no servers, no website accounts and no other users. The developer and the only user is the same person.

1. What shotbot does

shotbot saves highlight moments from public Polish GTA 6 live streams on Twitch and Kick, turns them into short vertical clips with subtitles and, only when the owner clicks an upload button, sends a chosen clip to the owner's own YouTube channel or to the owner's TikTok drafts.

2. Data shotbot accesses

  • Google / YouTube (YouTube Data API v3): the scope youtube.upload to upload a video the owner selected, and youtube.readonly to read the connected channel's name and ID, which are shown in the app so the owner can see which channel is connected.
  • TikTok (Login Kit, Content Posting API): the scope user.info.basic to read the account's open ID and display name, and video.upload to send a video to the account's drafts.
  • OAuth access tokens and refresh tokens issued by Google and TikTok.
  • Public stream data from Twitch and Kick (stream title, category, public chat messages) used to detect highlight moments. No private data of viewers is collected.

shotbot does not access email addresses, contacts, private videos, comments, analytics or any other account data.

3. How the data is used

  • Tokens are used only to upload the clips the owner chose and to show the connected account name.
  • Data is not used for advertising, profiling, analytics or training of AI models.
  • Data is not sold, rented or shared with any third party.

4. Google API Services User Data Policy

shotbot's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

5. Storage and security

  • Tokens are stored only in a local file on the owner's computer, readable only by the owner's user account.
  • They are sent only to the official Google and TikTok API servers over HTTPS, never anywhere else.
  • Clips are stored on the owner's own disk.

6. Retention and deletion

Tokens are kept until the owner clicks “Rozłącz” (Disconnect) in shotbot, which deletes them immediately. Access can also be revoked at any time at myaccount.google.com/permissions or in the TikTok app settings. Uploaded videos can be deleted in YouTube Studio or the TikTok app.

7. Children

shotbot is not directed at children and is used only by its adult owner.

8. Changes

Any change to this policy is published on this page with a new “Last updated” date.
